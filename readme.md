# 📝 Todo List Full Stack App

A full-stack Todo List application built with:

- **Frontend**: React
- **Backend**: Node.js + Express
- **Database**: MySQL

---

## 🚀 Features

- Add a new todo
- Mark todo as completed
- View all, active, or completed todos
- Delete todos
- Clear all completed todos
